## agh network digest-mode

Set one peer to digest delivery for a channel or one thread.

```
agh network digest-mode [flags]
```

### Options

```
      --channel string        Target channel
  -h, --help                  help for digest-mode
      --keyword stringArray   Keyword filter for this preference (repeatable)
      --peer string           Target peer id
      --thread string         Optional thread id
```

### Example

```bash
agh network digest-mode \
  --channel builders \
  --thread thread_release_check_20260416 \
  --peer patch-worker.session-19 \
  -o json
```
