## agh network subscriptions

Inspect network delivery preferences.

```
agh network subscriptions [command]
```

### Available Commands

```
list        List network delivery preferences
```

### List Options

```
      --channel string   Target channel
  -h, --help             help for list
      --limit int        Maximum number of preferences to return
      --peer string      Optional peer id filter
      --thread string    Optional thread id
```

### Examples

```bash
agh network subscriptions list --channel builders -o json
agh network subscriptions list --channel builders --thread thread_release_check_20260416 --peer patch-worker.session-19 -o json
```

### Options inherited from parent commands

```
      --json               Emit JSON output
  -o, --output string      Output format: human, json, jsonl, or toon (default "human")
      --workspace string   Workspace root, name, or ID for scoped network data
```
