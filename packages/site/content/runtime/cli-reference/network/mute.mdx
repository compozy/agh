## agh network mute

Mute one peer's network delivery for a channel or one thread. History remains readable through the
daemon control plane.

```
agh network mute [flags]
```

### Options

```
      --channel string        Target channel
  -h, --help                  help for mute
      --keyword stringArray   Keyword filter for this preference (repeatable)
      --peer string           Target peer id
      --thread string         Optional thread id
```

### Example

```bash
agh network mute --channel builders --thread thread_release_check_20260416 --peer patch-worker.session-19 -o json
```
