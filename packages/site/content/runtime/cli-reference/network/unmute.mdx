## agh network unmute

Remove one network delivery preference so the peer falls back to the next applicable row or default
routing.

```
agh network unmute [flags]
```

### Options

```
      --channel string   Target channel
  -h, --help             help for unmute
      --peer string      Target peer id
      --thread string    Optional thread id
```

### Example

```bash
agh network unmute --channel builders --thread thread_release_check_20260416 --peer patch-worker.session-19 -o json
```
