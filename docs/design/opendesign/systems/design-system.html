Design system

Canonical route chrome, page identity, and inventory patterns for the AGH operator UI. This document expands the catalog system into a page-level contract grounded in the shared @agh/ui primitives, production routes, and the supplied route captures.

catalog-design-system.html loops-catalog.html LISTING-STANDARD.md

Principles

01

Route chrome has three jobs, each with one owner. Separation removes the duplicated titles and drifting metadata visible across current pages.

Location

Topbar answers “where?”

Breadcrumb is the only identity on the leading edge. Optional route navigation stays centered. Actions terminate the row on the right.

Identity

Page head answers “what?”

The orange icon well, H1, count, status, description, and page metadata live inside content, never in the topbar.

Controls

Body answers “how?”

Search, filters, scope selectors, content tabs, and status summaries stay beside the content they change.

Canonical route stack

Topbar [breadcrumb · optional route nav · actions] → PageHead [icon · H1 · context] → content navigation / toolbar → route body.

Route navigation

06

Sister routes use real links inside a labeled nav. The neutral segmented appearance is visual only; Tabs remain for in-route panels and PillGroup remains a mode selector.

Routes

nav > a[aria-current]

Changes URL/history. Allowed in the topbar center zone.

Panels

Tabs / LaneTabs

Changes a panel in the same route. Place below the page head.

Modes

PillGroup

Changes scope or view mode. Place inside the body toolbar.

Migration checklist

15

Run this before migrating any route to the new page-level contract.

  • P0 Topbar = Breadcrumb · optional route navigation · right-aligned actions
  • P0 No route icon, H1, count, status, badge, search, or scope selector in the topbar
  • P0 Route navigation uses real links + aria-current; Tabs and PillGroup keep their original semantics
  • P0 Page Head owns the 24px orange icon well and the route’s single focusable H1
  • P0 Collection, detail, and compact pages map to PH1, PH2, or PH3 without new anatomy
  • P0 Topbar actions are 22px; one accent CTA; secondary → primary → overflow
  • P1 Search, filters, scopes, view modes, and content tabs stay in body chrome
  • P1 Long breadcrumbs truncate; narrow topbars collapse secondary actions before context
  • P1 Catalog toolbar remains Search → Filters → spacer → PillGroup Rows|Cards
  • P2 No accent side-stripes, gradients, duplicate titles, or invented status summaries
