# BUG-0023: The dev-cycle import tool is discoverable but unusable from public and loop action surfaces

- **Status:** open
- **Impact (user-side):** Blocks-Completion
- **Severity:** Critical · **Priority:** P0
- **Persona Affected:** Ada; Bruno
- **Journey Step:** J-07 Operate a Loop end-to-end as an autonomous agent via native tools, step 1; J-01 Run a default dev-cycle Loop to a verified finish, step 4
- **Scenarios:** LP-003;LP-045;LP-046
- **Found:** 2026-07-08 · **Report:** docs/qa/reports/2026-07-08-loops-refac.md
- **Origin:** n/a

## Summary

Ada can discover `ext__dev_cycle__import_tasks`, but cannot call it through the public `agh tool invoke` surface. The daemon reports the read-only extension tool as registered, enabled, available, authorized, and executable, then denies the call with `source_disabled`. After BUG-0021 was fixed in the worktree, the same contract gap also blocks `software-delivery`: its `load_tasks` action reaches `ext__dev_cycle__import_tasks`, but loop execution fails with `unknown_action_kind` because the extension tool is not routable as a loop action. This blocks both direct agent parity and the default software-delivery loop.

## Reproduction

- **Charter:** CH-027 · **Tour:** Feature Tour
- **Environment:** Ada / desktop / wifi-fast / en-US; fresh isolated QA lab `loops-refac-task-16-20260708-130224-745100`.

1. Start the isolated daemon with the bootstrap env from `docs/qa/reports/2026-07-08-loops-refac.md`.
2. Register the lab workspace as `loops-refac-task-16`.
3. Confirm the tool is discoverable:
   `agh tool info ext__dev_cycle__import_tasks -o json`
4. Invoke the tool from the public CLI surface:
   `agh tool invoke ext__dev_cycle__import_tasks --workspace loops-refac-task-16 --input '{"pattern":"/Users/pedronauck/dev/qa-labs/agh-loops-refac-task-16-20260708-130224-745100-lab/.compozy/tasks/loops-refac/task_*.md"}' -o json`

5. Retest `software-delivery` after the input-source coordinator fix from BUG-0021:
   `agh loop run --name software-delivery --workspace loops-refac-task-16-bug0021-retest --input slug=loops-refac -o json`
6. Inspect the `load_tasks` run:
   `agh task get loop.looprun-bcb599331fce4bcc.g2.node.load_tasks.0 -o json`

**Expected:** The tool returns `{tasks, count}` for the copied task graph, and deterministic validation errors for invalid inputs. The `software-delivery` `load_tasks` action consumes the same parser output and advances to `execute_task`.  
**Actual:** Direct call fails with `tool_denied`; tool diagnostics show `source_policy_result: denied` and `reason_codes: ["source_disabled"]` even though the descriptor is read-only and available. Loop action execution fails with `unknown_action_kind: tool "ext__dev_cycle__import_tasks" not found`.
